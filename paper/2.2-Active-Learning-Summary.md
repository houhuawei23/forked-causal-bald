# 2.2 主动学习 - 详细总结

## 一、标准主动学习设置

### 1.1 基本组成要素

**主动学习（Active Learning）**设置形式上由以下三个核心要素组成：

#### 1.1.1 未标记数据集（Unlabeled Dataset）

$$\mathcal{D}_{\text{pool}} = \{\mathbf{x}_{i}\}_{i=1}^{n_{\text{pool}}}$$

#### 符号说明

- **$\mathcal{D}_{\text{pool}}$**：**未标记数据集（Pool Dataset）**，也称为**池数据集（Pool Dataset）**
- **$\mathbf{x}_{i}$**：第 $i$ 个数据点的协变量（特征）
- **$n_{\text{pool}}$**：池数据集中数据点的数量

#### 1.1.2 标记训练集（Labeled Training Set）

$$\mathcal{D}_{\text{train}} = \{(\mathbf{x}_{i}, \mathrm{y}_{i})\}_{i=1}^{n_{\text{train}}}$$

#### 符号说明

- **$\mathcal{D}_{\text{train}}$**：**标记训练集（Labeled Training Set）**
- **$(\mathbf{x}_{i}, \mathrm{y}_{i})$**：第 $i$ 个训练样本，包含协变量 $\mathbf{x}_{i}$ 和对应的结果标签 $\mathrm{y}_{i}$
- **$n_{\text{train}}$**：训练集中样本的数量

#### 1.1.3 预测模型（Predictive Model）

模型由参数 $\boldsymbol{\omega} \sim p(\boldsymbol{\Omega} \mid \mathcal{D}_{\text{train}})$ 参数化，具有似然性：

$$p_{\boldsymbol{\omega}}(\mathrm{y} \mid \mathbf{x})$$

#### 符号说明

- **$\boldsymbol{\omega}$**：模型参数的具体实现
- **$\boldsymbol{\Omega}$**：模型参数的随机变量
- **$p(\boldsymbol{\Omega} \mid \mathcal{D}_{\text{train}})$**：给定训练数据时模型参数的**后验分布（Posterior Distribution）**
- **$p_{\boldsymbol{\omega}}(\mathrm{y} \mid \mathbf{x})$**：给定协变量 $\mathbf{x}$ 和参数 $\boldsymbol{\omega}$ 时，结果 $\mathrm{y}$ 的**似然函数（Likelihood Function）**

### 1.2 预言机假设

主动学习设置假设存在一个**预言机（Oracle）**，可为 $\mathcal{D}_{\text{pool}}$ 中的任何数据点提供结果 $\mathrm{y}$。

#### 含义解释

- 预言机能够为任何未标记的数据点提供真实标签
- 这在实际应用中可能对应人工标注、实验测量等方式
- 关键假设是标注是可行的，但可能成本较高，因此需要智能选择最有价值的数据点进行标注

### 1.3 采集函数与批量选择

在模型训练之后，根据一批数据的信息量，使用**采集函数（Acquisition Function）** $a$ 从 $\mathcal{D}_{\text{pool}}$ 中选择一批数据：

$$\{\mathbf{x}_{i}^{*}\}_{i=1}^{b}$$

#### 符号说明

- **$a$**：**采集函数（Acquisition Function）**，用于评估数据点的信息量
- **$\{\mathbf{x}_{i}^{*}\}_{i=1}^{b}$**：从池数据集中选择的一批数据点，共 $b$ 个
- **$b$**：**批量大小（Batch Size）**，每次选择的数据点数量

#### 含义解释

- 采集函数根据数据点的信息量（informativeness）进行评分
- 选择信息量最高的一批数据点进行标注
- 标注后的数据添加到训练集中，用于更新模型

## 二、治疗效果主动学习的特殊设置

### 2.1 与标准设置的差异

通过纳入治疗变量，本文偏离了标准的主动学习设置，针对**治疗效果（Treatment Effects）**的主动学习进行了特殊定义。

### 2.2 重新定义的数据集

#### 2.2.1 池数据集

$$\mathcal{D}_{\text{pool}} = \{(\mathbf{x}_{i}, \mathrm{t}_{i})\}_{i=1}^{n_{\text{pool}}}$$

#### 符号说明

- **$\mathbf{x}_{i}$**：第 $i$ 个数据点的协变量
- **$\mathrm{t}_{i}$**：第 $i$ 个数据点观察到的治疗方法（Treatment Assignment）
- 与标准设置不同，池数据集包含协变量和治疗分配信息

#### 2.2.2 训练集

$$\mathcal{D}_{\text{train}} = \{(\mathbf{x}_{i}, \mathrm{t}_{i}, \mathrm{y}_{i})\}_{i=1}^{n_{\text{train}}}$$

#### 符号说明

- 训练集包含三元组：协变量 $\mathbf{x}_{i}$、治疗分配 $\mathrm{t}_{i}$ 和结果 $\mathrm{y}_{i}$

#### 2.2.3 预测模型

模型由参数 $\boldsymbol{\omega} \sim p(\boldsymbol{\Omega} \mid \mathcal{D}_{\text{train}})$ 参数化，具有似然性：

$$p_{\boldsymbol{\omega}}(\mathrm{y} \mid \mathbf{x}, \mathrm{t})$$

#### 符号说明

- **$p_{\boldsymbol{\omega}}(\mathrm{y} \mid \mathbf{x}, \mathrm{t})$**：给定协变量 $\mathbf{x}$、治疗分配 $\mathrm{t}$ 和参数 $\boldsymbol{\omega}$ 时，结果 $\mathrm{y}$ 的似然函数
- 与标准设置不同，似然函数依赖于治疗分配 $\mathrm{t}$

### 2.3 采集函数的工作流程

#### 流程描述

1. 采集函数以 $\mathcal{D}_{\text{pool}}$ 作为输入
2. 返回一批数据 $\{(\mathbf{x}_{i}, \mathrm{t}_{i})\}_{i=1}^{b}$
3. 这些数据通过**神谕（Oracle）**进行标注（获取结果 $\mathrm{y}_{i}$）
4. 标注后的数据添加到 $\mathcal{D}_{\text{train}}$ 中

### 2.4 观察性研究场景

#### 特殊约束

本文特别研究的情况是：**只能获取池数据 $\{\mathrm{t}_{i}\}_{i=1}^{n_{\text{pool}}}$ 中观察到的治疗方法**，即**无法进行治疗分配（No Treatment Assignment）**的场景。

#### 含义解释

- 这是**观察性研究（Observational Study）**的设置
- 无法主动分配治疗，只能观察已有的治疗分配
- 与**随机对照试验（Randomized Controlled Trial, RCT）**不同，研究者不能控制治疗分配
- 这种设置更符合实际应用场景，但增加了因果推断的复杂性

## 三、标准主动学习与治疗效果主动学习的对比分析

### 3.1 核心要素对比表

| 要素 | 标准主动学习 | 治疗效果主动学习 | 改动说明 |
|------|------------|----------------|---------|
| **池数据集** | $\mathcal{D}_{\text{pool}} = \{\mathbf{x}_{i}\}_{i=1}^{n_{\text{pool}}}$ | $\mathcal{D}_{\text{pool}} = \{(\mathbf{x}_{i}, \mathrm{t}_{i})\}_{i=1}^{n_{\text{pool}}}$ | **新增治疗变量**：池数据集从仅包含协变量扩展为包含协变量和治疗分配的二元组 |
| **训练集** | $\mathcal{D}_{\text{train}} = \{(\mathbf{x}_{i}, \mathrm{y}_{i})\}_{i=1}^{n_{\text{train}}}$ | $\mathcal{D}_{\text{train}} = \{(\mathbf{x}_{i}, \mathrm{t}_{i}, \mathrm{y}_{i})\}_{i=1}^{n_{\text{train}}}$ | **新增治疗变量**：训练集从二元组扩展为三元组，包含协变量、治疗分配和结果 |
| **预测模型** | $p_{\boldsymbol{\omega}}(\mathrm{y} \mid \mathbf{x})$ | $p_{\boldsymbol{\omega}}(\mathrm{y} \mid \mathbf{x}, \mathrm{t})$ | **条件依赖扩展**：似然函数从仅依赖协变量扩展为同时依赖协变量和治疗分配 |
| **采集对象** | $\{\mathbf{x}_{i}^{*}\}_{i=1}^{b}$ | $\{(\mathbf{x}_{i}, \mathrm{t}_{i})\}_{i=1}^{b}$ | **采集内容扩展**：从仅选择协变量扩展为选择协变量和治疗分配的配对 |
| **研究场景** | 一般监督学习场景 | 观察性研究（Observational Study） | **场景约束**：无法主动分配治疗，只能观察已有的治疗分配 |

### 3.2 数据维度对比

| 维度 | 标准主动学习 | 治疗效果主动学习 |
|------|------------|----------------|
| **池数据维度** | $d$ 维（仅协变量） | $d + 1$ 维（协变量 + 治疗） |
| **训练数据维度** | $d + 1$ 维（协变量 + 结果） | $d + 2$ 维（协变量 + 治疗 + 结果） |
| **模型输入维度** | $d$ 维（仅协变量） | $d + 1$ 维（协变量 + 治疗） |
| **模型输出维度** | 1 维（结果） | 1 维（结果） |

### 3.3 工作流程对比

| 步骤 | 标准主动学习 | 治疗效果主动学习 |
|------|------------|----------------|
| **1. 初始化** | 给定未标记池 $\{\mathbf{x}_{i}\}$ 和初始训练集 $\{(\mathbf{x}_{i}, \mathrm{y}_{i})\}$ | 给定未标记池 $\{(\mathbf{x}_{i}, \mathrm{t}_{i})\}$ 和初始训练集 $\{(\mathbf{x}_{i}, \mathrm{t}_{i}, \mathrm{y}_{i})\}$ |
| **2. 模型训练** | 基于 $p_{\boldsymbol{\omega}}(\mathrm{y} \mid \mathbf{x})$ 训练模型 | 基于 $p_{\boldsymbol{\omega}}(\mathrm{y} \mid \mathbf{x}, \mathrm{t})$ 训练模型 |
| **3. 信息量评估** | 评估 $\{\mathbf{x}_{i}\}$ 的信息量 | 评估 $\{(\mathbf{x}_{i}, \mathrm{t}_{i})\}$ 的信息量 |
| **4. 数据选择** | 选择信息量高的 $\{\mathbf{x}_{i}^{*}\}$ | 选择信息量高的 $\{(\mathbf{x}_{i}, \mathrm{t}_{i})\}^{*}$ |
| **5. 标注获取** | 通过预言机获取 $\{\mathrm{y}_{i}^{*}\}$ | 通过预言机获取 $\{\mathrm{y}_{i}^{*}\}$（治疗分配已固定） |
| **6. 数据更新** | 将 $\{(\mathbf{x}_{i}^{*}, \mathrm{y}_{i}^{*})\}$ 添加到训练集 | 将 $\{(\mathbf{x}_{i}^{*}, \mathrm{t}_{i}^{*}, \mathrm{y}_{i}^{*})\}$ 添加到训练集 |

### 3.4 关键改动分析

#### 3.4.1 改动一：纳入治疗变量

**改动内容**：
- 在所有数据集中引入治疗变量 $\mathrm{t}$
- 模型从 $p_{\boldsymbol{\omega}}(\mathrm{y} \mid \mathbf{x})$ 扩展为 $p_{\boldsymbol{\omega}}(\mathrm{y} \mid \mathbf{x}, \mathrm{t})$

**改动意义**：
1. **因果推断需求**：治疗效果估计需要同时考虑协变量和治疗分配对结果的影响
2. **条件期望建模**：模型需要分别估计 $\mathbb{E}[\mathrm{Y} \mid \mathbf{X} = \mathbf{x}, \mathrm{T} = 1]$ 和 $\mathbb{E}[\mathrm{Y} \mid \mathbf{X} = \mathbf{x}, \mathrm{T} = 0]$，以计算 CATE
3. **治疗异质性**：允许模型捕捉治疗效应在不同协变量值下的异质性

#### 3.4.2 改动二：观察性研究约束

**改动内容**：
- 治疗分配 $\mathrm{t}_{i}$ 是观察到的，而非主动分配的
- 只能从池数据中已有的治疗分配进行选择

**改动意义**：
1. **实际应用性**：更符合真实世界的观察性研究场景（如医疗记录、社会调查等）
2. **伦理约束**：在某些场景下，主动分配治疗可能不道德或不可行
3. **混杂控制挑战**：由于无法随机化，需要更仔细地处理混杂因子，确保满足无混杂性假设
4. **重叠性关注**：需要特别关注治疗组和对照组在协变量空间的重叠性，避免选择重叠性差的区域

#### 3.4.3 改动三：采集策略的复杂性

**改动内容**：
- 采集函数需要评估 $(\mathbf{x}, \mathrm{t})$ 配对的信息量，而非仅评估 $\mathbf{x}$ 的信息量

**改动意义**：
1. **双重不确定性**：需要考虑协变量和治疗分配组合的不确定性
2. **CATE 不确定性**：采集函数应该优先选择能够减少 CATE 估计不确定性的数据点
3. **重叠性平衡**：需要平衡探索重叠性好的区域（满足假设 2.3）和重叠性差的区域（识别假设违反）
4. **治疗组平衡**：可能需要考虑治疗组和对照组之间的平衡，确保有足够的治疗和对照样本

### 3.5 改动带来的挑战与机遇

#### 3.5.1 主要挑战

| 挑战 | 描述 | 影响 |
|------|------|------|
| **混杂控制** | 无法随机化治疗分配，存在未观测混杂因子的风险 | 可能违反假设 2.2（无混杂性），导致 CATE 估计有偏 |
| **重叠性问题** | 某些协变量值可能只出现在治疗组或对照组 | 违反假设 2.3（重叠性），无法可靠估计 CATE |
| **采集策略设计** | 需要同时考虑协变量和治疗分配的信息量 | 采集函数设计更复杂，需要平衡多个目标 |
| **计算复杂度** | 模型输入维度增加，采集函数评估更复杂 | 计算成本可能增加 |

#### 3.5.2 主要机遇

| 机遇 | 描述 | 价值 |
|------|------|------|
| **实际应用性** | 适用于真实世界的观察性数据 | 提高方法的实用价值和可部署性 |
| **因果推断** | 直接支持个性化治疗效果估计 | 为精准医疗、个性化推荐等应用提供支持 |
| **不确定性量化** | 贝叶斯方法可以量化重叠性假设的违反 | 提供更可靠的估计和决策支持 |
| **主动学习价值** | 智能选择最有价值的数据点进行标注 | 在标注成本高的场景下，显著提高样本效率 |

### 3.6 理论联系

#### 3.6.1 与 CATE 估计的关联

治疗效果主动学习的改动直接服务于 CATE 估计的目标：

$$\tau(\mathbf{x}) = \mathbb{E}[\mathrm{Y}^{1} - \mathrm{Y}^{0} \mid \mathbf{X} = \mathbf{x}] = \mathbb{E}[\mathrm{Y} \mid \mathrm{T} = 1, \mathbf{X} = \mathbf{x}] - \mathbb{E}[\mathrm{Y} \mid \mathrm{T} = 0, \mathbf{X} = \mathbf{x}]$$

- **模型扩展**：$p_{\boldsymbol{\omega}}(\mathrm{y} \mid \mathbf{x}, \mathrm{t})$ 允许分别估计治疗组和对照组的条件期望
- **数据需求**：需要同时有治疗组和对照组的观测，强调重叠性的重要性
- **不确定性**：CATE 估计的不确定性不仅来自模型参数，还来自重叠性假设的违反

#### 3.6.2 与三个识别假设的关联

| 假设 | 标准主动学习 | 治疗效果主动学习 | 改动影响 |
|------|------------|----------------|---------|
| **一致性** | 通常隐含满足 | 需要显式考虑 | 采集策略需要确保观测结果与潜在结果一致 |
| **无混杂性** | 不相关 | **关键假设** | 采集策略需要考虑混杂因子的控制 |
| **重叠性** | 不相关 | **关键假设** | 采集策略需要优先选择重叠性好的区域，同时识别重叠性差的区域 |

### 3.7 总结

治疗效果主动学习对标准主动学习的改动体现了从**预测任务**到**因果推断任务**的范式转换：

1. **数据维度扩展**：从协变量-结果映射扩展为协变量-治疗-结果映射
2. **模型复杂度增加**：需要同时建模治疗组和对照组的条件分布
3. **约束条件增强**：观察性研究设置增加了混杂控制和重叠性要求
4. **采集策略优化**：需要设计专门针对 CATE 不确定性的采集函数

这些改动使得主动学习方法能够应用于因果推断场景，为个性化治疗效果估计提供了数据高效的解决方案。

## 四、不确定性的类型

### 3.1 两种不确定性来源

定义信息量的一种直观方法是使用模型的估计不确定性。一般来说，可以区分两种不确定性来源：

#### 3.1.1 认知不确定性（Epistemic Uncertainty）

**认知不确定性（Epistemic Uncertainty）**，也称为**模型不确定性（Model Uncertainty）**，源于对模型参数的无知。

#### 含义解释

- 这是由模型在训练期间未看到类似的数据点引起的
- 因此不清楚正确的标签会是什么
- 可以通过收集更多数据来减少
- 反映了模型知识的不足

#### 3.1.2 偶然不确定性（Aleatoric Uncertainty）

**偶然不确定性（Aleatoric Uncertainty）**，也称为**数据不确定性（Data Uncertainty）**，源于数据本身的随机性。

#### 含义解释

- 即使拥有完美的模型，数据本身也存在固有的随机性
- 无法通过收集更多数据来减少
- 反映了问题的内在不确定性

### 3.2 本文的焦点

本文专注于使用**认知不确定性（Epistemic Uncertainty）**来识别用于标签获取的最具信息量的点。

#### 原因

- 认知不确定性可以通过主动学习来减少
- 选择认知不确定性高的数据点进行标注，可以最有效地改善模型性能

## 四、BALD：通过分歧进行贝叶斯主动学习

### 4.1 BALD 的定义

**BALD（Bayesian Active Learning by Disagreement）**基于认知不确定性定义了一个采集函数。

### 4.2 互信息作为分歧度量

BALD 使用**未知输出（Unknown Output）**和**模型参数（Model Parameters）**之间的**互信息（Mutual Information, MI）**作为分歧的度量。

### 4.3 BALD 的数学表达式

$$\mathrm{I}(\mathrm{Y}; \boldsymbol{\Omega} \mid \mathbf{x}, \mathcal{D}_{\text{train}}) = \mathrm{H}(\mathrm{Y} \mid \mathbf{x}, \mathcal{D}_{\text{train}}) - \mathbb{E}_{\boldsymbol{\omega} \sim p(\boldsymbol{\Omega} \mid \mathcal{D}_{\text{train}})}[\mathrm{H}(\mathrm{Y} \mid \mathbf{x}, \boldsymbol{\omega})] \tag{1}$$

#### 符号说明

- **$\mathrm{I}(\mathrm{Y}; \boldsymbol{\Omega} \mid \mathbf{x}, \mathcal{D}_{\text{train}})$**：给定输入 $\mathbf{x}$ 和训练数据 $\mathcal{D}_{\text{train}}$ 时，输出 $\mathrm{Y}$ 和模型参数 $\boldsymbol{\Omega}$ 之间的**条件互信息（Conditional Mutual Information）**
- **$\mathrm{H}(\cdot)$**：**熵函数（Entropy Function）**
- **$\mathrm{H}(\mathrm{Y} \mid \mathbf{x}, \mathcal{D}_{\text{train}})$**：给定输入 $\mathbf{x}$ 和训练数据 $\mathcal{D}_{\text{train}}$ 时，输出 $\mathrm{Y}$ 的**条件熵（Conditional Entropy）**
- **$\mathrm{H}(\mathrm{Y} \mid \mathbf{x}, \boldsymbol{\omega})$**：给定输入 $\mathbf{x}$ 和参数 $\boldsymbol{\omega}$ 时，输出 $\mathrm{Y}$ 的条件熵
- **$\mathbb{E}_{\boldsymbol{\omega} \sim p(\boldsymbol{\Omega} \mid \mathcal{D}_{\text{train}})}[\cdot]$**：关于后验分布 $p(\boldsymbol{\Omega} \mid \mathcal{D}_{\text{train}})$ 的期望

#### 含义解释

- **互信息**衡量了观测到输出 $\mathrm{Y}$ 后，对模型参数 $\boldsymbol{\Omega}$ 的不确定性减少量
- 互信息越大，说明该数据点对减少参数不确定性越有价值
- 第一项 $\mathrm{H}(\mathrm{Y} \mid \mathbf{x}, \mathcal{D}_{\text{train}})$ 表示模型对输出的总体不确定性
- 第二项 $\mathbb{E}[\mathrm{H}(\mathrm{Y} \mid \mathbf{x}, \boldsymbol{\omega})]$ 表示给定参数时的平均不确定性
- 两者之差反映了参数不确定性对输出不确定性的贡献，即认知不确定性

### 4.4 离散结果的估计

对于具有**伯努利似然性（Bernoulli Likelihood）**或**分类似然性（Categorical Likelihood）**的离散结果，BALD 是一个直接的估计量。

#### 含义解释

- 对于离散结果，熵的计算是直接的
- 可以通过对后验分布进行采样来估计期望值

## 五、批量采集函数

### 5.1 批量 BALD 采集函数

基于 BALD 的用于在给定池数据集和模型参数的情况下获取一批数据点的一般采集函数由集合 $\{\mathrm{Y}_{i}\}$ 和模型参数之间的**联合互信息（Joint Mutual Information）**给出：

$$a_{\text{BALD}}(\mathcal{D}_{\text{pool}}, p(\boldsymbol{\Omega} \mid \mathcal{D}_{\text{train}})) = \underset{\{\mathbf{x}_{i}\}_{i=1}^{b} \subseteq \mathcal{D}_{\text{pool}}}{\arg \max} \mathrm{I}(\{\mathrm{Y}_{i}\}; \boldsymbol{\Omega} \mid \{\mathbf{x}_{i}\}, \mathcal{D}_{\text{train}}) \tag{2}$$

#### 符号说明

- **$a_{\text{BALD}}(\cdot)$**：**BALD 采集函数（BALD Acquisition Function）**
- **$\{\mathrm{Y}_{i}\}$**：一批数据点对应的输出集合
- **$\{\mathbf{x}_{i}\}_{i=1}^{b}$**：从池数据集中选择的一批输入，共 $b$ 个
- **$\mathrm{I}(\{\mathrm{Y}_{i}\}; \boldsymbol{\Omega} \mid \{\mathbf{x}_{i}\}, \mathcal{D}_{\text{train}})$**：给定输入集合和训练数据时，输出集合和模型参数之间的联合互信息
- **$\arg \max$**：使目标函数最大化的参数（这里是一批数据点的选择）

#### 含义解释

- 该函数选择使联合互信息最大化的一批数据点
- 联合互信息考虑了批量数据点之间的相关性
- 与独立选择数据点不同，批量选择可以更有效地利用数据点之间的依赖关系

### 5.2 独立评分的上界约束

#### 简化方法

这个批量采集函数可以通过独立地对 $\mathcal{D}_{\text{pool}}$ 中的每个点进行评分并取前 $b$ 个来进行**上界约束（Upper Bound Approximation）**。

#### 数学表达

$$\text{独立评分方法：选择 } \{\mathbf{x}_{i}\}_{i=1}^{b} \text{ 使得 } \sum_{i=1}^{b} \mathrm{I}(\mathrm{Y}_{i}; \boldsymbol{\Omega} \mid \mathbf{x}_{i}, \mathcal{D}_{\text{train}}) \text{ 最大}$$

#### 问题

然而，这个界限忽略了样本之间的相关性。

#### 实际影响

- 对于具有大量重复的数据集，这种方法可能比随机采集表现更差
- 因为独立评分没有考虑数据点之间的信息重叠
- 选择的数据点可能包含冗余信息

### 5.3 BatchBALD 的解决方案

计算**联合互信息（Joint Mutual Information）**（如 **BatchBALD** 中引入的）纠正了这个问题。

#### 含义解释

- **BatchBALD** 明确计算批量数据点的联合互信息
- 考虑了数据点之间的相关性
- 避免了选择信息冗余的数据点

## 六、计算效率的考虑

### 6.1 联合互信息的计算成本

估计联合互信息在计算上很昂贵，因为需要：

#### 6.1.1 分类任务

评估所有可能结果上的**联合熵（Joint Entropy）**

#### 6.1.2 回归任务

评估所有输入上的**协方差矩阵（Covariance Matrix）**

#### 含义解释

- 随着批量大小 $b$ 的增加，计算复杂度呈指数增长
- 对于大规模数据集，精确计算联合互信息可能不可行

### 6.2 Softmax-BALD：高效的替代方法

#### 6.2.1 方法描述

一种替代方法是使用 **softmax-BALD**，它涉及在 $\mathcal{D}_{\text{pool}}$ 上进行**重要性加权采样（Importance-Weighted Sampling）**，其个体重要性权重由 BALD 给出。

#### 6.2.2 数学表达

$$\text{重要性权重：} w_{i} = \mathrm{I}(\mathrm{Y}_{i}; \boldsymbol{\Omega} \mid \mathbf{x}_{i}, \mathcal{D}_{\text{train}})$$

$$\text{采样概率：} p_{i} = \frac{\exp(w_{i}/\tau)}{\sum_{j=1}^{n_{\text{pool}}} \exp(w_{j}/\tau)}$$

其中 $\tau$ 是温度参数。

#### 符号说明

- **$w_{i}$**：第 $i$ 个数据点的 BALD 分数（重要性权重）
- **$p_{i}$**：第 $i$ 个数据点被选中的概率
- **$\tau$**：**温度参数（Temperature Parameter）**，控制采样的锐度

#### 6.2.3 优势

本文使用 **softmax-BALD** 进行批量采集，因为：

1. **计算效率高**：避免了计算联合互信息的昂贵操作
2. **与 BatchBALD 具有竞争力**：在保持计算效率的同时，性能接近精确的批量方法

### 6.3 与 CATE 的关联

本文将在第 3 节中讨论：

1. **BALD 如何映射到 CATE 中的认知不确定性量化**
2. **由于重叠问题而产生的复杂情况**

#### 含义解释

- 将 BALD 应用于 CATE 估计时，需要考虑治疗效果的特定性质
- 重叠性问题（假设 2.3）会影响不确定性量化
- 需要开发针对因果推断的特殊采集策略

## 七、总结

### 7.1 核心概念链

1. **标准主动学习**：从未标记池中选择信息量高的数据点进行标注
2. **治疗效果主动学习**：在观察性研究设置下，选择最有价值的 $(\mathbf{x}, \mathrm{t})$ 对进行结果标注
3. **认知不确定性**：通过 BALD 量化，用于指导数据选择
4. **批量采集**：考虑数据点相关性的联合互信息 vs. 计算高效的 softmax-BALD

### 7.2 关键创新点

- 将主动学习扩展到治疗效果估计场景
- 考虑观察性研究的约束（无法主动分配治疗）
- 使用认知不确定性指导数据采集
- 平衡计算效率与性能的批量采集策略

### 7.3 与后续内容的关联

- BALD 在 CATE 估计中的应用
- 重叠性问题对不确定性量化的影响
- 因果推断特定的采集函数设计
