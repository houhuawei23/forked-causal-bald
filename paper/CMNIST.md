## "响应面是基于数字投影到潜在的一维流形上生成的"的含义

### 1. **核心概念**

- **响应面（Response Surface）**：结果变量 Y 与协变量 X 和治疗 T 的函数关系，即 $Y = f(X, T)$
- **潜在的一维流形（Latent 1-dimensional Manifold）**：一个一维的潜在混杂协变量 $\phi$，是真正的因果变量
- **投影（Projection）**：将高维 MNIST 图像（784 维）映射到一维的 $\phi$ 值

### 2. **生成过程详解**

#### 步骤 1：从 MNIST 数字到潜在变量 $\phi$

```python
# 从代码中可以看到投影过程：
# 1. 计算每个数字图像的平均像素强度
means = x_ind.mean(axis=-1)  # 对每个28x28图像求平均

# 2. 对每个数字类别(0-9)，计算其均值和标准差
mu = means.mean()  # 该类别的平均强度
sigma = means.std()  # 该类别的强度标准差

# 3. 将强度标准化并映射到一维流形上
z[ind] = linear_normalization(
    np.clip((means - v["mu"]) / v["sigma"], -1.4, 1.4), 
    v["lo"], v["hi"]  # 映射到[-3, 3]区间
)
```

投影规则：
- 先按图像强度（像素平均值）排序
- 再按数字类别（0-9）映射到不同区间
- 最终得到一维的 $\phi \in [-3, 3]$

#### 步骤 2：基于 $\phi$ 生成响应面

```python
# 响应面函数 f_mu
def f_mu(x, t, u, gamma=4.0):
    mu = (
        (2 * t - 1) * x          # 治疗效应项
        + (2.0 * t - 1)           # 常数项
        - 2 * np.sin((4 * t - 2) * x)  # 非线性项
        - (gamma * u - 2) * (1 + 0.5 * x)  # 混杂项
    )
    return mu
```

其中：
- `x` 是 $\phi$（一维流形上的值）
- `t` 是治疗（0 或 1）
- `u` 是未观测的混杂因子（设为 0）

### 3. **为什么这样设计？**

- 真实场景：观测到高维特征（如医学图像），但真正的混杂变量是低维的（如病情严重程度）
- 挑战：模型需要从高维代理中学习到低维的 $\phi$，才能正确估计因果效应
- 测试：模型必须隐式学习从 MNIST 数字到 $\phi$ 的非线性映射

### 4. **可视化理解**

```
MNIST 数字 (784维)  →  投影函数  →  φ (1维)  →  f_mu(φ, t)  →  Y (响应)
   [高维代理]          [非线性映射]   [真实混杂]    [响应面]      [结果]
```

### 5. **实际意义**

- MNIST 数字是 $\phi$ 的高维代理（proxy）
- $\phi$ 是真正的混杂协变量，影响治疗分配和结果
- 响应面基于 $\phi$ 而非原始图像生成，因此模型需要学习从图像到 $\phi$ 的映射

总结：将高维 MNIST 图像投影到一维的 $\phi$，然后基于 $\phi$ 生成响应面。这模拟了从高维观测数据中学习低维因果结构的问题。

## CMNIST 数据集中的"治疗"是什么？

### 1. **治疗变量的定义**

在 CMNIST 中，**治疗 T 是一个二元变量**：
- **T = 1**：接受治疗（治疗组）
- **T = 0**：未接受治疗（对照组）

### 2. **治疗如何分配？**

治疗不是随机分配的，而是根据**倾向得分（Propensity Score）**随机分配，模拟观察性研究中的选择偏差：

```python
# 步骤1：计算倾向得分 π
self.pi = utils.complete_propensity(x=phi, u=0.0, lambda_=1.0, beta=beta)

# 步骤2：根据倾向得分进行二项分布采样
self.t = rng.binomial(1, self.pi).astype("float32")
```

### 3. **倾向得分的计算**

倾向得分 $\pi(\phi) = P(T=1 \mid \phi)$ 基于潜在混杂变量 $\phi$ 计算：

```python
def nominal_propensity(x, beta=0.75):
    logit = beta * x + 0.5
    return (1 + np.exp(-logit)) ** -1  # sigmoid函数
```

这意味着：
- $\phi$ 值越大，接受治疗的概率越高
- 治疗分配依赖于协变量，存在选择偏差

### 4. **治疗对结果的影响**

治疗通过响应面函数影响结果：

```python
# 对照组的结果期望
self.mu0 = utils.f_mu(x=phi, t=0.0, u=0.0, gamma=0.0)

# 治疗组的结果期望  
self.mu1 = utils.f_mu(x=phi, t=1.0, u=0.0, gamma=0.0)

# 实际观测到的结果（根据实际分配的治疗）
self.y = self.t * self.y1 + (1 - self.t) * self.y0
```

### 5. **实际意义**

在 CMNIST 中，治疗是一个**抽象概念**，不代表具体医疗干预，而是：
- 用于测试因果推断方法
- 模拟观察性研究中的治疗分配机制
- 测试模型在存在选择偏差时估计治疗效果的能力

### 6. **关键特点**

1. 非随机分配：治疗分配依赖于协变量 $\phi$（通过倾向得分）
2. 存在混杂：$\phi$ 同时影响治疗分配和结果
3. 二元治疗：只有两种状态（0 或 1）

总结：CMNIST 中的“治疗”是一个二元变量（0/1），根据基于潜在混杂变量 $\phi$ 的倾向得分进行分配，用于模拟观察性研究中的治疗分配机制。
