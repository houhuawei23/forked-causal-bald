# 基于贝叶斯统计决策的因果主动学习研究报告

## 摘要

本报告结合贝叶斯统计决策课程的理论知识与 Causal-BALD 项目的实践，系统性地介绍了基于贝叶斯方法的因果推断主动学习框架。报告首先回顾了贝叶斯统计的核心概念，包括后验分布、贝叶斯推断、贝叶斯决策以及信息论在主动学习中的应用。然后深入分析了 Causal-BALD 方法，该方法将贝叶斯主动学习与因果推断相结合，通过信息论获取函数在治疗效应估计中实现了样本效率的提升。实验结果表明，该方法在合成数据集、IHDP 和 CMNIST 等数据集上显著优于基线方法，验证了贝叶斯方法在因果推断主动学习中的有效性。

**关键词：** 贝叶斯统计、因果推断、主动学习、个性化治疗效应、信息论

## 1. 背景介绍

### 1.1 因果推断与个性化治疗效应估计

在现代机器学习与统计学习中，因果推断是一个重要且具有挑战性的领域。在医学、政策制定、推荐系统等实际应用中，我们常常需要回答"如果采取不同的行动，结果会如何变化"这类因果问题。

在因果推断的框架中，我们关注的核心概念是**个性化治疗效应（Individual Treatment Effect, ITE）**。对于个体 $u$，其个体治疗效果定义为：

$$\text{ITE}(u) = Y^1(u) - Y^0(u)$$

其中 $Y^1(u)$ 表示接受治疗时的潜在结果，$Y^0(u)$ 表示未接受治疗时的潜在结果。然而，由于因果推断的**根本问题（Fundamental Problem of Causal Inference）**，我们无法同时观察到同一个体的两种潜在结果。

因此，在实际应用中，我们转而估计**条件平均治疗效果（Conditional Average Treatment Effect, CATE）**：

$$\tau(\mathbf{x}) = \mathbb{E}[Y^1 - Y^0 \mid \mathbf{X} = \mathbf{x}]$$

在满足一致性（Consistency）、无混杂性（Unconfoundedness）和重叠性（Overlap）三个假设的条件下，CATE 可以从观测数据中识别：

$$\tau(\mathbf{x}) = \mathbb{E}[Y \mid T=1, \mathbf{X}=\mathbf{x}] - \mathbb{E}[Y \mid T=0, \mathbf{X}=\mathbf{x}]$$

其中 $T \in \{0,1\}$ 表示治疗分配，$\mathbf{X}$ 表示协变量向量。

### 1.2 贝叶斯方法在因果推断中的应用

在本课程中，我们学习了贝叶斯统计的核心思想：**将未知参数视为随机变量，利用先验信息与样本信息，通过贝叶斯公式得到后验分布**。贝叶斯公式可以表示为：

$$p(\boldsymbol{\theta} \mid \mathcal{D}) = \frac{p(\mathcal{D} \mid \boldsymbol{\theta}) p(\boldsymbol{\theta})}{p(\mathcal{D})} = \frac{p(\mathcal{D} \mid \boldsymbol{\theta}) p(\boldsymbol{\theta})}{\int p(\mathcal{D} \mid \boldsymbol{\theta}') p(\boldsymbol{\theta}') d\boldsymbol{\theta}'}$$

其中：
- $p(\boldsymbol{\theta})$ 是先验分布（Prior Distribution），代表我们对参数 $\boldsymbol{\theta}$ 的先验知识
- $p(\mathcal{D} \mid \boldsymbol{\theta})$ 是似然函数（Likelihood），表示数据在给定参数下的概率
- $p(\boldsymbol{\theta} \mid \mathcal{D})$ 是后验分布（Posterior Distribution），综合了先验信息和样本信息
- $p(\mathcal{D})$ 是边际似然（Marginal Likelihood），作为归一化常数

在因果推断中，贝叶斯方法具有以下优势：

1. **不确定性量化**：通过后验分布，我们可以量化模型参数的不确定性，从而量化 CATE 估计的不确定性。这对于理解估计的可靠性至关重要。

2. **认知不确定性建模**：在课程中我们学习了认知不确定性（Epistemic Uncertainty）和偶然不确定性（Aleatory Uncertainty）的区别。对于因果推断，认知不确定性反映了我们对模型参数知识的缺乏，而这种不确定性可以通过获取更多数据来减少。

3. **信息论基础**：贝叶斯方法天然地与信息论结合。**互信息（Mutual Information）**可以作为衡量数据点信息量的指标：

$$\text{I}(Y; \boldsymbol{\Omega} \mid \mathbf{x}, \mathcal{D}_{\text{train}}) = \text{H}(Y \mid \mathbf{x}, \mathcal{D}_{\text{train}}) - \mathbb{E}_{\boldsymbol{\omega} \sim p(\boldsymbol{\Omega} \mid \mathcal{D}_{\text{train}})}[\text{H}(Y \mid \mathbf{x}, \boldsymbol{\omega})]$$

其中 $\text{H}(\cdot)$ 表示熵，$\boldsymbol{\Omega}$ 表示模型参数的随机变量。

### 1.3 主动学习框架

主动学习（Active Learning）是一种半监督学习方法，其核心思想是：**让模型主动选择最有价值的未标记数据进行标注，从而用更少的标注样本达到更好的性能**。

在因果推断的主动学习设置中，我们面临以下场景：

- **池数据集（Pool Dataset）**：$\mathcal{D}_{\text{pool}} = \{(\mathbf{x}_i, t_i)\}_{i=1}^{n_{\text{pool}}}$，包含协变量和治疗分配，但没有结果标签
- **训练集（Training Set）**：$\mathcal{D}_{\text{train}} = \{(\mathbf{x}_i, t_i, y_i)\}_{i=1}^{n_{\text{train}}}$，包含已标注的结果
- **获取函数（Acquisition Function）**：$a(\mathcal{D}_{\text{pool}}, p(\boldsymbol{\Omega} \mid \mathcal{D}_{\text{train}}))$，用于从池数据中选择最有信息量的样本

主动学习的流程如下：

1. 使用初始训练集训练模型，得到后验分布 $p(\boldsymbol{\Omega} \mid \mathcal{D}_{\text{train}})$
2. 使用获取函数在池数据集中选择一批样本 $\{(\mathbf{x}_i^*, t_i^*)\}_{i=1}^b$
3. 通过"神谕"（Oracle，如医生的诊断、实验测量等）获取这些样本的结果 $y_i^*$
4. 将新标注的样本加入训练集，重新训练模型
5. 重复步骤 2-4，直到达到性能要求或预算耗尽

### 1.4 贝叶斯主动学习与因果推断的结合

将贝叶斯方法应用于因果推断的主动学习，我们面临一个关键挑战：**传统主动学习关注预测的不确定性，但在因果推断中，我们需要关注治疗效应的可识别性**。

具体而言，即使模型对某个数据点的结果预测不确定性很高，如果该点位于治疗组和对照组非重叠的支持区域（Non-overlapping Support），我们仍然无法估计该点的治疗效应。因此，**一个好的因果主动学习获取函数应该同时考虑信息增益和重叠性（Overlap）**。

这正是 Causal-BALD 方法要解决的核心问题。

## 2. 方法介绍：Causal-BALD

### 2.1 问题设定

在 Causal-BALD 中，我们使用深度贝叶斯模型来估计 CATE。模型参数 $\boldsymbol{\omega} \sim p(\boldsymbol{\Omega} \mid \mathcal{D}_{\text{train}})$ 的后验分布通过深度核高斯过程（DUE）或深度集成等方法获得。

对于给定协变量 $\mathbf{x}$ 和治疗分配 $t$，模型的预测为：

$$\hat{\mu}_{\boldsymbol{\omega}}(\mathbf{x}, t) = \mathbb{E}[Y \mid T=t, \mathbf{X}=\mathbf{x}, \boldsymbol{\omega}]$$

相应地，CATE 估计为：

$$\hat{\tau}_{\boldsymbol{\omega}}(\mathbf{x}) = \hat{\mu}_{\boldsymbol{\omega}}(\mathbf{x}, 1) - \hat{\mu}_{\boldsymbol{\omega}}(\mathbf{x}, 0)$$

我们的目标是从池数据集中选择能够最大化学习 CATE 效率的样本。

### 2.2 朴素采集函数及其局限性

在介绍 Causal-BALD 之前，让我们先分析几种朴素的采集函数，它们展示了为什么需要专门针对因果推断设计的获取函数。

#### 2.2.1 随机采集（Random Acquisition）

最简单的采集策略是随机选择：

$$a_{\text{random}}(\mathcal{D}_{\text{pool}}) = \text{随机选择} \{(\mathbf{x}_i, t_i)\}_{i=1}^b$$

**问题**：随机采集反映了池数据中的固有偏差。如果池数据的模式与非重叠区域重合，该策略会频繁获取无信息的样本，导致资源过度分配到分布的模式上。

![图1：观测数据示例](paper/images/1.jpg)

#### 2.2.2 反事实倾向获取（Counterfactual Propensity Acquisition）

基于倾向得分的获取函数：

$$a_{\pi}(\mathbf{x}, t) = 1 - \hat{\pi}_t(\mathbf{x})$$

其中 $\hat{\pi}_t(\mathbf{x}) = P(T=t \mid \mathbf{X}=\mathbf{x})$ 是倾向得分估计量。

**问题**：虽然这种方法倾向于选择反事实观察概率较高的点，但仍会使数据选择偏向池数据的模式，无法有效处理弱重叠区域。

![图2：朴素采集函数的影响](paper/images/2.jpg)

#### 2.2.3 $\tau$-BALD

直接基于 CATE 不确定性的获取函数：

$$\text{I}(Y^1 - Y^0; \boldsymbol{\Omega} \mid \mathbf{x}, t, \mathcal{D}_{\text{train}}) \approx \text{Var}_{\boldsymbol{\omega} \sim p(\boldsymbol{\Omega} \mid \mathcal{D}_{\text{train}})}[\hat{\mu}_{\boldsymbol{\omega}}(\mathbf{x}, 1) - \hat{\mu}_{\boldsymbol{\omega}}(\mathbf{x}, 0)]$$

**问题**：这是一个**不可约的不确定性度量**。如果在未观察到的治疗 $t'$ 的情况下对标签不确定，$\tau$-BALD 就会很高，无论在实际治疗 $t$ 的情况下对结果的确定性如何。这使得 $\tau$-BALD 在低密度区域和没有重叠的区域最高，导致无信息的获取。

#### 2.2.4 $\mu$-BALD

基于可观测结果不确定性的获取函数：

$$\text{I}(Y^t; \boldsymbol{\Omega} \mid \mathbf{x}, t, \mathcal{D}_{\text{train}}) \approx \text{Var}_{\boldsymbol{\omega} \sim p(\boldsymbol{\Omega} \mid \mathcal{D}_{\text{train}})}[\hat{\mu}_{\boldsymbol{\omega}}(\mathbf{x}, t)]$$

**问题**：$\mu$-BALD 只包含可观察的量，但没有考虑我们对反事实结果的信念。当我们对 $(\mathbf{x}, t')$ 也非常不确定时，即使 $(\mathbf{x}, t')$ 不在池数据中，这种方法也可能倾向于获取 $(\mathbf{x}, t)$。由于我们既不能减少对这种 $(\mathbf{x}, t')$ 的不确定性，也不知道治疗效果，所以获取函数在数据效率方面不是最优的。

从上述分析可以看出，朴素方法要么只考虑重叠（如倾向得分获取），要么只考虑信息增益（如 $\tau$-BALD、$\mu$-BALD），但都忽略了另一个重要方面。

### 2.3 Causal-BALD 方法

Causal-BALD 方法的核心创新在于**同时考虑信息增益和重叠性**。论文提出了三种获取函数：$\mu\pi$-BALD、$\rho$-BALD 和 $\mu\rho$-BALD。

#### 2.3.1 $\mu\pi$-BALD：简单乘法结合

第一种方法是将 $\mu$-BALD 与倾向得分获取项相乘：

$$\text{I}(\mu\pi \mid \mathbf{x}, t, \mathcal{D}_{\text{train}}) = (1 - \hat{\pi}_t(\mathbf{x})) \cdot \text{Var}_{\boldsymbol{\omega} \sim p(\boldsymbol{\Omega} \mid \mathcal{D}_{\text{train}})}[\hat{\mu}_{\boldsymbol{\omega}}(\mathbf{x}, t)]$$

**直觉**：
- $(1 - \hat{\pi}_t(\mathbf{x}))$ 项鼓励选择反事实观察概率高的点（即重叠区域）
- $\text{Var}_{\boldsymbol{\omega}}[\hat{\mu}_{\boldsymbol{\omega}}(\mathbf{x}, t)]$ 项鼓励选择信息增益高的点

**优点**：简单直观，易于实现

**缺点**：在高维情况下，倾向得分估计可能不准确，导致性能下降

#### 2.3.2 $\rho$-BALD：信息论方法

$\rho$-BALD 采用更严格的信息论方法，定义为：

$$\text{I}(Y^t; \hat{\tau}_{\boldsymbol{\Omega}} \mid \mathbf{x}, t, \mathcal{D}_{\text{train}}) \gtrapprox \frac{1}{2}\log\left(\frac{\text{Var}_{\boldsymbol{\omega}}[\hat{\mu}_{\boldsymbol{\omega}}(\mathbf{x}, t)] - 2\text{Cov}_{\boldsymbol{\omega}}[\hat{\mu}_{\boldsymbol{\omega}}(\mathbf{x}, t), \hat{\mu}_{\boldsymbol{\omega}}(\mathbf{x}, t')]}{\text{Var}_{\boldsymbol{\omega}}[\hat{\mu}_{\boldsymbol{\omega}}(\mathbf{x}, t')]} + 1\right)$$

其中 $t' = 1-t$ 表示反事实治疗。

**核心思想**：
1. 通过反事实结果方差 $\text{Var}_{\boldsymbol{\omega}}[\hat{\mu}_{\boldsymbol{\omega}}(\mathbf{x}, t')]$ 的倒数进行缩放，使采集偏向于我们已知反事实结果的示例（满足重叠）
2. 通过协方差项 $\text{Cov}_{\boldsymbol{\omega}}[\hat{\mu}_{\boldsymbol{\omega}}(\mathbf{x}, t), \hat{\mu}_{\boldsymbol{\omega}}(\mathbf{x}, t')]$ 进行折扣，这是一个有待深入讨论的概念

**优点**：理论严格，不依赖倾向得分估计

**缺点**：在某些情况下可能导致次优的数据效率

#### 2.3.3 $\mu\rho$-BALD：最佳组合（推荐方法）

$\mu\rho$-BALD 结合了 $\mu$-BALD 和 $\rho$-BALD 的优点：

$$\text{I}(\mu\rho \mid \mathbf{x}, t, \mathcal{D}_{\text{train}}) = \text{Var}_{\boldsymbol{\omega}}[\hat{\mu}_{\boldsymbol{\omega}}(\mathbf{x}, t)] \cdot \frac{\text{Var}_{\boldsymbol{\omega}}[\hat{\tau}_{\boldsymbol{\omega}}(\mathbf{x})]}{\text{Var}_{\boldsymbol{\omega}}[\hat{\mu}_{\boldsymbol{\omega}}(\mathbf{x}, t')]}$$

**直觉**：
- $\text{Var}_{\boldsymbol{\omega}}[\hat{\mu}_{\boldsymbol{\omega}}(\mathbf{x}, t)]$：对当前治疗结果的不确定性
- $\frac{\text{Var}_{\boldsymbol{\omega}}[\hat{\tau}_{\boldsymbol{\omega}}(\mathbf{x})]}{\text{Var}_{\boldsymbol{\omega}}[\hat{\mu}_{\boldsymbol{\omega}}(\mathbf{x}, t')]}$：对治疗效应不确定性的归一化度量（考虑重叠）

这样，在比率可能相等的情况下，更倾向于当前模型更不确定的数据点，同时在重叠假设满足的区域内更均匀地分布。

![图3：Causal-BALD 获取函数的效果](paper/images/3.jpg)

从图 3 可以看出，$\mu\rho$-BALD 的训练数据采集在满足重叠假设的池数据支持上分布得更加均匀，CATE 估计器在该区域的准确性最高。

### 2.4 贝叶斯决策理论视角

从贝叶斯决策理论的角度来看，Causal-BALD 获取函数实际上是在优化一个**信息论损失函数**。

在课程中，我们学习了**抽样信息期望值（Expected Value of Sampling Information, EVSI）**的概念：

$$\text{EVSI} = \mathbb{E}_{\mathcal{D}}[\max_{\boldsymbol{\omega}} U(\boldsymbol{\omega}, \mathcal{D})] - \max_{\boldsymbol{\omega}} \mathbb{E}_{\mathcal{D}}[U(\boldsymbol{\omega}, \mathcal{D})]$$

其中 $U(\boldsymbol{\omega}, \mathcal{D})$ 是效用函数。

在主动学习中，我们选择数据点 $\mathbf{x}^*$ 以最大化：

$$\mathbf{x}^* = \arg\max_{\mathbf{x} \in \mathcal{D}_{\text{pool}}} \text{EVSI}(\mathbf{x})$$

Causal-BALD 的获取函数可以看作是对 EVSI 的近似，其中：
- 效用函数是 CATE 估计的准确性
- 信息增益通过互信息量化
- 重叠性约束确保治疗效应的可识别性

## 3. 实验

### 3.1 实验设置

#### 3.1.1 数据集

实验使用了三个数据集，涵盖了不同的挑战和场景：

**1. 合成数据集（Synthetic Dataset）**

设计用于展示各种偏差模式的数据集。主要特点：
- 包含一个主要数据模式
- 设计有弱重叠或无重叠区域
- 用于说明不同获取函数的行为

![合成数据集可视化](assets/synthetic_dataset.png)

**2. IHDP 数据集**

因果治疗效果文献中的标准基准数据集，源自真实的随机对照试验：
- 样本数：747 个
- 协变量维度：25 维
- 特点：包含真实的治疗分配和结果数据
- 挑战：存在选择偏差

**3. CMNIST 数据集**

基于 MNIST 的高维、大样本数据集：
- 样本数：35,000+
- 输入：MNIST 手写数字图像
- 特点：模型需要隐式学习从高维图像到潜在一维流形 $\phi$ 的非线性映射
- 挑战：高维输入空间、非线性响应面

![CMNIST 数据集示例](assets/cmnist_dataset.png)

#### 3.1.2 模型

实验使用**深度核高斯过程（Deep Kernel Gaussian Process, DUE）**作为基础模型：

**为什么选择 DUE？**
- DUE 是深度核学习的一个实例，使用深度特征提取器转换输入
- 在提取的特征表示上定义高斯过程核，能够处理高维数据
- 使用变分诱导点近似和谱归一化，实现可靠的不确定性量化
- DUE 在 IHDP 数据集上取得了最优结果

**模型架构**：
- 深度特征提取器：包含残差连接和谱归一化
- 高斯过程层：使用变分诱导点近似
- 区分模型参数 $\boldsymbol{\theta}$ 和变分参数 $\boldsymbol{\omega}$，仅对 $\boldsymbol{\omega}$ 采用贝叶斯方法

由于 DUE 是高斯过程，我们可以直接获得结果的全高斯后验分布，从中可以使用均值和协方差。采样非常高效，只需要在深度模型中进行一次前向传播。

#### 3.1.3 基线方法

实验与以下基线方法进行比较：

1. **随机（Random）**：随机均匀选择点
2. **倾向得分（Propensity Score）**：基于倾向得分（公式 4）的获取函数
3. **$\gamma$（Sigmoid Error Rate）**：Sundin 等人提出的基于 S 型错误率的方法，调整用于贝叶斯深度神经网络

#### 3.1.4 评估指标

使用**精确估计异质效应（Precision in Estimation of Heterogeneous Effect, PEHE）**的平方根作为评估指标：

$$\sqrt{\epsilon_{\text{PEHE}}} = \sqrt{\frac{1}{N}\sum_{\mathbf{x}} (\hat{\tau}(\mathbf{x}) - \tau(\mathbf{x}))^2}$$

其中 $\tau(\mathbf{x})$ 是真实的 CATE，$\hat{\tau}(\mathbf{x})$ 是估计的 CATE。

#### 3.1.5 主动学习参数

每个数据集的主动学习参数如下表所示：

| 数据集 | 热身大小 | 获取大小 | 获取步数 | 池大小 | 验证大小 |
|--------|----------|----------|----------|--------|----------|
| Synthetic | 10 | 10 | 30 | 10k | 1k |
| IHDP | 100 | 10 | 38 | 471 | 201 |
| CMNIST | 250 | 50 | 55 | 35k | 15k |

其中：
- **热身大小**：初始训练集中的样本数量
- **获取大小**：每个获取步骤中标注的样本数量
- **获取步数**：查询一批标签的次数
- **池大小**：池数据集中的样本数量
- **验证大小**：用于模型选择的验证集大小

#### 3.2.3 维度影响分析

论文的一个重要发现是不同方法对协变量维度的敏感性：

- **$\rho$-BALD**：性能随着协变量维度的增加而提高
- **$\mu\pi$-BALD**：性能随着协变量维度的增加而变差（因为倾向得分估计在高维情况下存在问题）
- **$\mu$-BALD 和 $\mu\rho$-BALD**：在所有三个任务中的两项上表现稳定，$\mu\rho$-BALD 相对于 $\mu$-BALD 有统计学上的显著改进

这些结果表明：
1. **$\mu\rho$-BALD 比 $\mu\pi$-BALD 更稳健**，特别是在高维协变量的情况下
2. **$\mu\rho$-BALD 不需要额外的倾向得分模型**，简化了实现

### 3.3 实验分析

#### 3.3.1 为什么 Causal-BALD 有效？

1. **同时优化信息增益和重叠性**：$\mu\rho$-BALD 通过在信息增益项上乘以重叠归一化项，确保选择的数据点既具有高信息量，又位于可识别治疗效应的区域。

2. **避免不可约不确定性**：与 $\tau$-BALD 不同，$\mu\rho$-BALD 避免了选择位于非重叠区域的样本，这些样本即使不确定性很高也无法提供有用的信息。

3. **处理高维数据**：不依赖倾向得分估计，使得方法在高维情况下更加稳健。

#### 3.3.2 从贝叶斯视角的理解

从贝叶斯统计的角度，Causal-BALD 的成功可以理解为：

1. **后验分布的充分利用**：通过后验分布 $p(\boldsymbol{\Omega} \mid \mathcal{D}_{\text{train}})$，我们能够量化不同数据点对模型参数信息增益的贡献。

2. **信息论原理**：互信息作为信息增益的度量，在贝叶斯框架下自然地出现，反映了我们从观察新数据中可以获得的期望信息。

3. **决策理论优化**：获取函数本质上是在优化一个信息论损失函数，这与贝叶斯决策理论中的 EVSI 概念一致。

#### 3.3.3 局限性

实验也揭示了一些局限性：

1. **无混杂假设的依赖**：方法假设无混杂性成立，但在存在隐藏混杂因子的情况下，可能导致有偏采样。

2. **计算成本**：虽然使用了变分近似，但在大规模数据集上，计算后验分布仍然需要一定的计算资源。

3. **批量获取的次优性**：当前使用 softmax-BALD 进行批量获取，忽略了样本之间的相关性，可能与 BatchBALD 存在差距。

## 4. 总结与展望

### 4.1 贝叶斯主动学习方法的优势

结合课程内容和 Causal-BALD 项目的实践，我认为贝叶斯主动学习方法在因果推断中具有以下优势：

1. **理论严谨性**：基于信息论和贝叶斯决策理论，有坚实的数学基础。互信息作为信息增益的度量，在贝叶斯框架下自然出现。

2. **不确定性量化**：能够区分认知不确定性和偶然不确定性，这对于理解估计的可靠性至关重要。在因果推断中，认知不确定性的量化帮助我们识别哪些区域的估计是不可靠的。

3. **样本效率**：通过主动选择最有信息量的样本，能够用更少的标注数据达到更好的性能。这在标注成本高昂的场景（如医学诊断）中尤为重要。

4. **处理复杂模型**：与深度学习方法结合，能够处理高维、非线性问题，如 CMNIST 数据集中的图像数据。

5. **自适应性**：随着获取更多数据，后验分布不断更新，模型能够自适应地调整获取策略。

### 4.2 贝叶斯主动学习方法的局限性

然而，方法也存在一些局限性：

1. **先验选择的敏感性**：在课程中我们学习了先验分布的重要性。不合适的先验可能导致后验分布偏离真实情况，影响获取函数的效果。

2. **计算复杂度**：虽然使用了变分近似等方法，但在大规模数据集上，计算后验分布和获取函数仍然需要一定的计算资源。MCMC 方法（如课程中介绍的 Metropolis-Hastings、Gibbs 抽样）虽然理论上更准确，但计算成本更高。

3. **假设的强依赖**：方法依赖于无混杂性假设，但在实际应用中，隐藏混杂因子可能是普遍存在的。这可能导致有偏的采样和估计。

4. **批量获取的挑战**：当前的方法主要关注单点获取，批量获取时如何考虑样本之间的相关性仍然是一个开放问题。

5. **验证集的依赖**：方法假设可以访问验证集进行模型选择，但在实际应用中这可能不可用。

### 4.3 未来研究方向

基于课程学习和项目实践，我认为未来可以在以下方向进行深入研究：

#### 4.3.1 放宽假设条件

1. **处理隐藏混杂**：将关于隐藏混杂的信念纳入获取函数，放宽无混杂性假设。这可能涉及敏感性分析或结构因果模型。

2. **弱重叠处理**：研究如何在弱重叠（Weak Overlap）的情况下设计获取函数，利用 D'Amour 和 Franks 提出的去混杂得分（Deconfounding Scores）。

#### 4.3.2 改进计算方法

1. **更高效的批量获取**：研究更严格的批量获取方法，如改进的 BatchBALD，以更好地考虑样本之间的相关性。

2. **可扩展的贝叶斯推断**：结合课程中学习的 MCMC 方法，研究在大规模数据上的可扩展贝叶斯推断，如随机梯度 MCMC。

3. **主动验证数据获取**：研究主动获取验证数据的方法，以在验证集不可用时进行模型选择。

#### 4.3.3 应用拓展

1. **多治疗设置**：将方法扩展到多治疗（Multi-treatment）场景，而不仅仅是二元治疗。

2. **连续治疗**：研究如何处理连续治疗变量，这在实际应用中也很常见。

3. **动态治疗策略**：结合强化学习，研究动态治疗策略的主动学习。

#### 4.3.4 理论深化

1. **信息论分析**：深入研究不同获取函数的信息论性质，如它们对 CATE 估计误差的收敛速度的影响。

2. **贝叶斯决策理论**：结合课程中学习的贝叶斯决策理论，研究更一般的损失函数下的最优获取策略。

3. **有限样本理论**：建立有限样本下的理论保证，分析样本复杂度。

### 4.4 课程学习总结

通过学习贝叶斯统计决策课程并完成 Causal-BALD 项目，我深刻理解了：

1. **贝叶斯思维的重要性**：将未知参数视为随机变量，通过先验和似然得到后验，这种思维方式在不确定性量化中非常重要。

2. **信息论与贝叶斯的结合**：互信息作为信息增益的度量，在贝叶斯框架下自然地出现，为主动学习提供了理论指导。

3. **理论与实践的平衡**：虽然理论很重要，但在实际应用中，计算效率和可扩展性同样重要。变分推断、MCMC 等方法都是在理论和实践之间的权衡。

4. **领域知识的融入**：在因果推断中，仅仅使用通用的主动学习方法是不够的，需要结合领域知识（如重叠性假设）来设计更好的方法。

5. **不确定性量化的重要性**：在医疗等高风险应用中，理解估计的不确定性至关重要，这正是贝叶斯方法的优势所在。

#### 6.1.1 获取函数实现

项目中的获取函数实现在 `causal_bald/library/acquisitions.py`：

```python
def mu_rho(mu_0, mu_1, t, pt, temperature):
    """μρ-BALD: 结合 μ-BALD 和 ρ-BALD 的推荐方法"""
    return mu(mu_0, mu_1, t, pt, temperature) + rho(mu_0, mu_1, t, pt, temperature)

def mu(mu_0, mu_1, t, pt, temperature):
    """μ-BALD: 基于可观测结果不确定性的获取函数"""
    return (1 / temperature) * np.log((t * mu_1.var(0) + (1 - t) * mu_0.var(0)) + _eps)

def rho(mu_0, mu_1, t, pt, temperature):
    """ρ-BALD: 关注重叠区域的获取函数"""
    return tau(mu_0, mu_1, t, pt, temperature) - mu(mu_0, mu_1, 1 - t, pt, temperature)
```
